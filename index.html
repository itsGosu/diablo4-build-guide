Build Summary

This guide is based only on the provided screenshots. It is designed to be reusable for other builds by editing the build data object near the bottom of this HTML file.

Class: Barbarian Archetype: Whirlwind / Channeling Theme: Berserking Scaling: Resolve / Overpower / Crit

Primary Engines

  • Berserking uptime powers damage, damage reduction, and set bonuses.
  • Resolve stacking appears across helm, chest, pants, boots, amulet, and aspects.
  • Overpower stacks are supported by Banished Lord's Talisman and several item affixes.
  • Ramaladni's Magnum Opus converts Fury into damage scaling.
  • Melted Heart of Selig redirects damage into primary resource for survivability.
